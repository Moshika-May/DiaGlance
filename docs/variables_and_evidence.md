# ตัวแปรที่รวบรวม: เกี่ยวข้องกับโรคเบาหวานอย่างไร (ข้อมูลของเรา + งานวิจัย)

เอกสารนี้สรุป (1) ตัวแปรเป้าหมายและตัวแปรอธิบายที่เรามีข้อมูลรายจังหวัด (2) งานวิจัยที่เกี่ยวข้อง และกลไกที่ "น่าจะ" เชื่อมโยง (3) ผลจริงจากข้อมูลของเรา (4) ตัวแปรที่ยังไม่ได้ข้อมูล

> ข้อควรระวังก่อนอ่าน: เนื้อหาในคอลัมน์ "งานวิจัย" มาจากการอ่านบทคัดย่อ/ข้อความย่อที่ค้นพบ ผมไม่ได้อ่านฉบับเต็มทุกฉบับ ตัวเลขควรตรวจกับต้นฉบับก่อนอ้างอิงในรายงานทางการ ส่วน "กลไก" คือสมมติฐานที่เป็นไปได้ ไม่ใช่ข้อเท็จจริงที่ข้อมูลของเราพิสูจน์

## 2. ตัวแปรอธิบาย: ข้อมูลของเรา, งานวิจัย, กลไก, ผล

ระดับหลักฐาน: **A** ผลระดับบุคคล/กลุ่มติดตามหลายงานและสอดคล้องกัน · **B** งานระดับจังหวัดในไทย · **C** อ่อนหรือผลปนกัน · **D** ไม่พบงานที่เชื่อมโดยตรง

ผลของเรา = ผลระดับจังหวัด หลังคุมภาค ความหนาแน่น และสัดส่วน 60+ (β ต่อ +1 SD, p-value, Holm-p ปรับตามจำนวนตัวแปรที่ลอง) ดูตารางเต็มที่ `data/canonical/analysis_report.md`

**หมายเหตุสำคัญเรื่องกลุ่มที่ "เกือบมีนัยสำคัญ"** (ไฟฟ้ารวม, หย่า, สมรส, GPP): ตัวแปรเหล่านี้สัมพันธ์กันสูง (หย่า–สมรส 0.94, หย่า–GPP 0.79) น่าจะวัดสิ่งเดียวกันคือความคึกคักทางเศรษฐกิจ/การลงทะเบียนของจังหวัดนั้น ไม่ควรเลือกตัวเดียวมาเล่าเรื่อง ผ่าน FDR (q≈0.03) แต่เฉียดผ่านเกณฑ์ Holm (≈0.05) จึงต้องถือว่า **ยังไม่ยืนยัน**

## 3. สิ่งที่ข้อมูลของเรา "ยังบอกไม่ได้"
- เหตุและผล: เป็นข้อมูลระดับจังหวัด (76 จุด) บอกว่าจังหวัดที่ X มาก มักมีเบาหวานมาก/น้อยกว่า ไม่ได้บอกว่าคนที่ได้รับ X เป็นเบาหวานมากขึ้น (ecological fallacy)
- ผลลัพธ์ขึ้นกับการตรวจคัดกรอง: จังหวัดที่ตรวจมากย่อมพบมาก
- จังหวัดข้างเคียงไม่เป็นอิสระต่อกัน (ยังไม่ได้ใช้โมเดลเชิงพื้นที่)
- กรุงเทพฯ ขาดตัวแปรเป้าหมาย

| **วิดีโอเกม** | ไม่พบงานที่วัดผลต่อเบาหวานในผู้ใหญ่โดยตรง มีเพียงงานตัดขวางในนักเล่นเกมผู้ใหญ่ ([Arnaez 2018](https://games.jmir.org/2018/2/e12), [Scoggins 2025](https://frontiersin.org/articles/10.3389/fspor.2024.1520202/full)) | data.go.th มีแค่ปฏิทินอีสปอร์ตของศรีสะเกษ และตาราง NSO ระดับภาค/ประเทศ ไม่มีรายจังหวัด |
| **Netflix / โรงหนัง** | อยู่ในกลุ่มเวลาหน้าจอ (ไม่มีงานเฉพาะ) | ไม่มีข้อมูลสาธารณะรายจังหวัด |
| **การพนัน / หวย** | ผลปนกัน: บางงานพบโอกาสเบาหวานสูงขึ้นในผู้เล่น ([Missouri Medicine 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12021406/), [UCLA](https://healthpolicy.ucla.edu/our-work/publications/how-does-gambling-correlate-chronic-health-conditions)) งานแคนาดาไม่พบหรือพบทางลบ ([ualberta wp 2011-18](https://sites.ualberta.ca/~econwps/2011/wp2011-18.pdf)) ส่วนใหญ่เป็นงานตัดขวาง | มีเฉพาะตัวชี้วัดสุขภาพจิตเกี่ยวกับการพนัน (HDC `s_mental_gambling`) ซึ่งยังไม่ได้ตรวจความหมายของคอลัมน์ จึงยังไม่ใส่ในโมเดล |
| **สุนัขจรจัด / อาชญากรรม / ฟิตเนส** | ไม่พบงานที่เชื่อมโดยตรง | ไม่มีข้อมูลรายจังหวัดครบ |

## 5. สรุปสั้น
1. **ตัวกำหนดหลักของเบาหวานรายจังหวัดในข้อมูลเราคืออายุและภาค** ไม่ใช่สภาพแวดล้อมแต่ละตัวที่เราไล่เก็บ
2. ความสัมพันธ์ดิบที่ดูน่าสนใจ (ปั๊มน้ำมัน สนามกีฬา ติดทะเล วัด) **หายไปเกือบหมดเมื่อคุมภาคและความหนาแน่น**
3. สัญญาณที่เหลือ (ไฟฟ้ารวม หย่า สมรส GPP) เป็นตัวแทนของ "ความคึกคักทางเศรษฐกิจ" ซึ่งยังไม่ยืนยัน และทิศทางต่างจากงานวิจัยบางชิ้น
4. ตัวแปรที่งานวิจัยสนับสนุนมากที่สุด (ร้านอาหาร/สะดวกซื้อ, เครื่องดื่มหวาน, เวลาหน้าจอ) เป็นตัวที่เรา**ยังไม่มีข้อมูลระดับจังหวัดที่ใช้ได้** นี่คือช่องว่างสำคัญของโครงงาน
